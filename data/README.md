`originals/SHA256SUMS` 记录原始文件的 SHA-256，可在项目根目录验证：

```bash
(cd data/originals && shasum -a 256 -c SHA256SUMS)
```

`analysis/d3-3087666-20261022/report.json` 中的抓包和参考 CSV 绝对路径是当时分析环境的历史来源信息，本目录没有对应原始抓包。不要把报告中的旧路径当作当前项目文件。

正在使用的完整档案与同步游标仍在项目根目录的 `archive/`。整理仅调整上述资料的位置，不修改文件内容、原始资料、数据库、导出、备份或迁移证据。

统一查询数据库位于 `archive/library.sqlite`，与这些历史资料分开；导出及备份见[主 README](../README.md)。上述三个资料目录均不进入 Git；新克隆的代码仓库只包含此说明，不自带观测记录、分析结果或截图。

后续研究按 `analysis/设备或主题-日期/` 新建目录，同次分析的文件放在一起，避免再次散落到根目录。`model-probes/` 中已有验收文件保持原路径，方便现有文档查证。
