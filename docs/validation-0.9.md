# 0.9 验收记录

日期：2026-10-27。范围为目录、文档和 TUI 交互迭代；数据库保持 schema 4，没有改变设备通信协议或下载事务。本轮未连接设备、写设备参数或重新采集，硬件能力沿用 [0.8 实测边界](validation-0.8.md)。

## 用户可见结果

- 配置编辑后先展示设备编号、旧值、新值及影响，确认后才写入；结果未确认时必须先回读。
- 帮助与日志可在设备页和结果页打开并返回原页；页面绘制层与键盘路由一致。
- 百台设备列表与结果支持翻页、首尾导航、逐台预览和导出。批量重试保留未完成目标及地址/并发参数，跳过成功及明确不可重试项。
- Ctrl+A 勾选附近可采集项、u 清空；表单支持光标编辑、删除、中文和长路径窗口。
- 设备页 f 闪灯、b 备份；主列表 Esc 留在列表，q 退出。取消等待后台清理，不重复发送 SIGINT。
- README 作为快速入门，详细操作、命令和维护规范各自成篇。用户无需理解 SQLite 才能完成日常操作。

## 自动化验收

230 项测试在 Python 3.14.3 与 Python 3.15.1 通过，统一使用 `tests/run.py` 隔离默认数据与配置。相对于 0.8 的 210 项，新增 20 项工作流测试，包括：

| 范围 | 核查 |
| --- | --- |
| 导航 | 百台首尾、结果选中项与导出目标、帮助返回保留选择 |
| 配置 | 第一次 Enter 不写、第二次才写、返回编辑、启动失败保留表单、未知值禁改、未确认状态禁改 |
| 编辑 | 中文中间插入、Delete、Ctrl+U、长文本可见窗口 |
| 批量 | 附近全选排除离线/冲突/未适配项、清空、重试地址保持对应 |
| 后台 | 无法启动时显示错误、畸形事件/结果拒绝、取消只发一次中断 |
| 排版 | 68×18、100×24、140×40；全部叠层不越界，中文折行不丢字符 |
| 结果 | pending 不误报正式保存 |

既有协议、校验、持久化、故障恢复、迁移、备份、配置和并发隔离测试同时回归。测试数量不代表全部真实设备和固件均实测。
