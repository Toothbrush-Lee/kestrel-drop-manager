# 单台设备数据管理

在已登记设备上按 **h**。页面先读取电脑摘要，不连接蓝牙。管理编号与序列号保持固定，切换下载勾选不会改变已打开页面的目标；此页只处理当前这一台。

官方LiNK手册第21页明确区分Clear Device History（App内历史）和Clear Device Log（设备内部日志），Auto Sync Log为连接时同步。本实现遵循这一区分：[官方使用手册](https://kestrelinstruments.com/mwdownloads/download/link/id/1083)。按本轮需求，不加入GPS。

| 截图项目 | TUI位置与含义 |
| --- | --- |
| Last Log | 页顶显示电脑已同步的末条，按采集序号确定；不是设备当前RTC |
| Sync Log | s，执行现有完整/增量同步，显示百分比和条数 |
| Export Log | e，导出电脑当前已保存的记录，可筛选时间；输出文件不覆盖旧文件 |
| Device Sync Rate | r读取后按1，设备实时测量传输/刷新间隔，2–60秒；不是历史下载轮询间隔 |
| Data Logging Rate | r读取后按2，设备保存日志的采样间隔，如300秒=5分钟 |
| Wrap Log | r读取后按3，on满后覆盖最早记录，off满后停止追加；电脑记录不受影响 |
| Auto Sync Log | 4，按设备保存到本机，默认关闭，连接时先同步一次 |
| Clear Device History | 7，仅清电脑该设备历史，先备份；设备日志不改 |
| Clear Device Log | 8，先同步并备份，再清设备日志；电脑历史不删 |

其他键：r连接读取设备设置，c只读设备日志总条数，i刷新本机摘要，v预览，b备份，l查看完整任务日志和备份路径，Esc返回。设备设置显示上次读取的快照，没有读到的字段禁止编辑；配置确认和逐字段回读沿用原有流程。

## 自动同步的准确含义

TUI按操作建立短连接，并不永久占用设备。开启后，读取设备设置、写设置、闪灯、读取实时值，以及明确登记时，会在连接并核验身份后先同步一次；设置/实时操作尽量复用同一连接。已经是手动同步的连接不再嵌套同步。若同步还有未确认数据或失败，不继续配置写入。

纯扫描、identify只读身份核验、电脑数据查询、浏览前端、导出及device-count不会触发自动同步；未打开TUI或未发起操作时也不会后台定时扫描。偏好只保存在电脑，不改设备日志间隔、时间或安全设置，也不影响手机App自己的偏好。经常读取设置时，开启自动同步会增加传输工作量。

清除电脑历史后，如果设备仍有日志，下一次手动/自动同步可能重新下载，这是预期行为。

## 清除电脑历史（7）

1. 读取本机摘要后选择7，输入本台完整厂家序列号，不能只填管理编号。
2. 检查目标、电脑正式记录和暂存块数量，Enter再次确认；Esc返回或取消。
3. 程序取得目录锁，核对确认版本戳，自动生成并完整校验独立SQLite备份。
4. 在一个事务中删除该设备全部正式观测、暂存、下载会话和历史段，新建空历史；同时写入清除审计。任何失败回滚。

设备登记、固定管理编号、当前受试者代号、自动同步偏好和既有操作审计保留；其他设备不改。已导出CSV和旧备份也不会被删除，所以“清除电脑历史”不等于永久销毁所有副本。下次同步从头请求设备仍保留的日志。

## 清除设备日志（8）

1. 输入完整序列号并再次确认；不支持批量。
2. 重新连接并读取硬件身份，必须与目标一致。
3. 在同一连接上同步并校验可读取的增量，提交到电脑。未确认/失败时中止，不发送清除。
4. 自动生成完整独立备份，核对备份与当前档案一致，保存清除前审计。
5. 按355207 Rev G命令1擦除设备日志，收到匹配ACK后用命令2读总条数，严格核对0条后才显示成功。

电脑观测、游标、编号、受试者代号和其他设备不删；不发送校时、停止记录或恢复出厂命令。官方序号为生命周期递增，不能因擦除flash就把电脑游标归零；后续继续增量。

**此操作不中止采样。最后同步到擦除之间仍可能产生新记录，因此不承诺零丢样。** 请在适合清理设备的时段执行。擦除后若很快产生新记录，读到非零条不能直接解释成失败；程序会报待核对，而不再擦除一次。

## 断线、取消与恢复

ACK丢失、断线或取消可能发生在擦除已经生效之后。程序不自动重试清除，写入failed_or_unknown审计（审计存储本身失败时会明确报告）。返回h页按c只读查询设备条数，必要时s保存新增记录，再查看审计，不通过重复清除来“试试看”。

c查询只核验身份并读总条数，不会触发自动同步、清除或写设置。电脑清除如在提交附近被取消，也应先i刷新实际数量；不能仅凭“取消”推断未生效。

备份路径在结果与l日志中。需要恢复时，使用原有restore流程恢复到空目录进行核对，不能覆盖正在使用的数据库。备份包含整个档案库和研究代号，应与原始数据同样保管。

## 版本与验证范围

schema 6仅新增自动同步偏好表，升级前保存schema5-before-upgrade备份，旧库只读不会自动升级。初次使用新功能或显式migrate后，旧软件不能打开schema 6，请先升级采集程序。

本轮通过真实协议编码的模拟设备、临时SQLite库和worker/TUI交互测试；没有对工作档案清除记录，也没有向实机发送擦除指令。官方定义已核对，但不同固件的真实擦除行为仍需在可清理的测试设备上另行验证。
