| D1 | 9 字节 | 0 时间、2 温度 | d1-9-v1 |

187 项测试分别在 Python 3.14.3、3.15.0 上通过。新增或调整验证覆盖：

- D1/D2 原生首次下载、增量、零新增幂等和中断后的连续边界。
- D1/D2 待确认块备份、恢复边界；无完成确认时继续保持未确认，直到后续有效完成事务。
- 缺少字段严格为 NULL，D1 预览显示 --，负温度和负露点保留符号。
- 错误字段声明、缺少声明、长度错误的块在相应 ACK 前拒绝；写盘失败不 ACK，完成发布先于最终 ACK。
- schema 2 原有 D3 正式记录、游标及待确认块保留；只读不升级；升级前备份；DDL 故障完整回滚且可重试。
- 默认未勾选批量仅选择本次扫描到的可采集设备，明确勾选离线设备仍可重试；单台失败继续后续任务。
