# 0.10 验收记录

日期：2026-10-27。取消快扫，修正下载选择范围，加入批量配置。SQLite schema 4 保持不变。设备通信沿用已验证的单台官方配置实现，硬件验证边界见 [0.8 记录](validation-0.8.md)。

## 用户操作契约

- s 默认扫描 15 秒，S 仅作为相同操作的别名，不再提供快扫/长扫两套入口；CLI 可显式指定超时。已知地址发现即连接的优化继续保留。
- 空格勾选，A/Ctrl+A 全选本次附近可采集项，u 清空。Enter/a 有勾选时只处理所选，与当前光标位置无关。
- 没有勾选时 Enter 处理当前设备，a 提示先选择。空集合不会扩大成全部附近设备。成功的新扫描会清除旧勾选；有无效所选项时整次不启动。
- 有勾选时 g 打开批量设置，无勾选时 g 读取当前设备。批量支持时间、采样间隔、覆盖策略和实时更新间隔；表单固定目标，确认页可以浏览全部设备，再确认才写入。
- 批量逐台核验真实身份、读取本台旧值、仅修改所选字段并回读，保留独立审计。now 在每台实际写入时取电脑时间，不复制第一台的旧时间。
- 单台设备错误后继续，取消时报告当前结果未知及后续未执行，已成功项不回滚。配置不会自动重试；结果页 g 可只读核对当前设备。

共 268 项测试在 Python 3.14.3 和 Python 3.15.1 通过，统一从隔离入口 tests/run.py 运行。本轮新增 20 项，覆盖：

| 配置确认 | g/3/Enter 仅生成预览、二次确认才启动、表单固定目标、Esc 保留编辑、百台目标首尾导航 |

## 交互与数据边界

使用真实 PTY 检查三台离线模型的 A → g → 3 → Enter 确认名单 → Enter 提交 → q；命令被截获并核查为 set-batch、三个明确编号及对应地址、--time now --execute，没有实际执行 BLE 或设备写入。

批量写入为逐台操作，不是跨设备原子事务，也不是高精度同时同步。真实设备尚未执行本轮批量校时；模拟回读与审计成功不能代替不同现场与固件的全部实测。

当前档案、备份、原件与官方资料只读核查，保留原位；本轮末段回归前后 SHA-256 核查与测试日志保存在本地 data/analysis/batch-0.10-20261027/。本轮不迁移或重写正式观测，不清空设备。
