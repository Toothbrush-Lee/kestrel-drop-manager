日期：2026-10-26。代码 0.8.0，活动数据库 schema 4。原始官方资料与本地实机证据不纳入 Git。

## 自动化测试

210 项测试在 Python 3.14.3 / 3.15.0 下验证，覆盖原有数据持久化、故障恢复和迁移流程，并补充：

- 官方 20 字节分块、转义跨块、补零、CRC、128 字节接收上限与通用 ACK。
- 超过 32 位的历史序号、完整 64 位完成序号、拒绝截短完成消息和明确 NACK 原因。
- 24 位热指数含高位正数；schema 3 备份核验、重新解码及失败时整个事务回滚。
- 两台并发上限、连接槽位复用、混合 D1/D2/D3 独立原始载荷及事件归属、单台失败继续、取消全部清理。
- 设置参数、ASCII 名称、日期和范围校验，未选择和保留字节保持，写入回读不一致拒绝报告成功。
- 写入前审计的可见性，部分生效后失联的未知状态，审计备份保留，错误身份从不写入。
- 标准及带零填充的时间读取、校时命令与回读；校时导致时间倒退仍按序号连续保存，最新记录按序号查询。
- TUI 单项配置提交、非法输入不启动任务、独立设备进度、并发数选择、配置页面取消和外部数据变化自动刷新。

模拟测试不等同于所有固件和百台现场实测。较早一项 CLI 测试未指定临时目录，曾触发活动库自动升级；已改为显式临时目录；新增 `tests/run.py`，同时隔离默认数据目录与设置文件，作为推荐测试入口。该升级使用了正常备份和事务路径，后续逐条核验确认四台设备原始记录与游标未受影响。

## 官方接口实测

| 实机 | 固件 | 验证内容 |
| --- | --- | --- |
| D1 2509793 | 1.56 | 型号、序列号、设置、硬件版本、电量特征及 Get Time；并发增量历史 |
| D3 3087666 | 1.61 | 同上；相同设置回写、回读及审计；六项实时测量 |

两台均返回 300 秒采样、开启滚动覆盖；D1 实时更新为 60 秒，D3 为 5 秒。直接时间特征返回无效零值，改用命令 14 后可正确读取；返回中的第八字节零填充已做明确兼容。

D3 的设置实测仅把刚读取到的相同间隔与覆盖开关写回；前后全部 20 字节一致，审计为 verified。没有对真实设备执行名称、参考海拔、实时更新率修改或校时，也没有清空记录、恢复默认、停止记录或刷固件。

D3 实时特征的六项测量均返回存在、启用、有效状态，无读取错误；实时数据不写入历史库。电量为固件报告值，不用它推断日志容量或丢弃记录。
