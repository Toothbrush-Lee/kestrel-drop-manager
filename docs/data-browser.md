# 在本机浏览观测数据

数据浏览使用成熟的 Streamlit 组件。采集程序仍负责扫描和下载；这个页面只查询同一个 SQLite 档案，支持同时选择多台设备，在同一时间范围内查看数值和对比变化。

## 启动

在源码项目文件夹打开终端，运行：

```sh
uv run --extra viewer kestrel.py browse
```

首次需要联网安装可选组件。终端随后显示本机地址，通常会自动打开浏览器：<http://127.0.0.1:8501>。保持终端运行，结束时在终端按 Ctrl+C。无需打开蓝牙或连接设备；可以与采集程序同时运行。

独立采集运行包保持轻量，**没有捆绑浏览组件**。目前请在源码环境运行上述命令，或在 Python 环境安装带扩展的包：`pip install 'kestrel-drop-manager[viewer] @ /绝对路径/安装包.whl'`，然后运行 `kestrel-drop browse`。

如果页面没有原来的数据，核对左侧显示的数据库位置。它与采集端使用相同的目录选择规则；可以明确指定：

```sh
uv run --extra viewer kestrel.py --data-dir '/绝对路径/原数据目录' browse
```

不要指定 `library.sqlite` 文件本身，应指定其所在目录。路径不对时会报错，不会创建一个空档案。页面不执行迁移；旧档案需要先由采集程序按升级流程处理。

端口被其他程序占用时改为 `browse --port 8502`。不希望自动打开窗口时加 `--no-open`，自行访问终端显示的地址。

## 查看与导出

1. 左侧“设备（可多选）”选择1–100台，也可“全选设备”或“清空选择”。可搜索管理编号、序列号、当前受试者代号或别名；窄窗口可展开左侧筛选栏。已登记的空设备仍可选。
2. 默认查看所选设备中最晚记录之前约24小时，所有设备共用同一个范围。选择开始、结束日期时间后，点击“应用筛选”。范围按分钟选择，包含结束分钟的全部秒值。也可点击“全部历史”或“最近24小时”。
3. 页面显示已应用范围、合计记录总数、有数据设备数和实际最早/最晚时间。新增“各设备最新数值”表，每台一行，显示当前范围内按历史段和设备序号排列的末条原始记录、记录时间和所选指标。它不是实时蓝牙数据，各台记录时间可以不同；无记录或不支持的指标显示“—”，不填零。修改控件但尚未应用时，结果仍对应原来显示的已应用范围。
4. 选择要看的指标，同图按设备分色；拖动或缩放点图，悬停查看设备编号、原始时间、历史段、设备序号与测量值。未记录的指标不补零。
5. 表格每页100、200或500条，使用上一页/下一页翻页。默认按序列号、历史段和设备序号排列，列头排序只对当前页有效。
6. “准备导出筛选结果”后点击下载CSV，可获取所有所选设备的整个已应用时间选区、序列号及全部测量字段；上限按所有设备合计计算。表格自身的下载按钮只导出当前页，不能当作完整导出。

刚完成新一轮下载后，点击“刷新数据”。页面不自动轮询，也不会扫描或下载设备。刷新不会自动移动已应用的时间上限；要包含更新的数据，可再点“最近24小时”或“全部历史”。已准备的CSV是当时的快照，获取最新导出应再次点击准备。

## 时间与完整性

- 筛选、图表和CSV使用**设备原始本地时间**，没有推断时区或换算UTC。设备时钟不准时，先按其记录时间扩大范围查找。
- 校时可能导致时间重复或倒退。同一时间对应的不同序号仍保留，不能根据时间戳去重。历史段也用于区分清空或重置后的采集。
- 图表使用点而不连接插值，避免在时间跳变处画出误导性的连续线；相同时间和值的点可能重叠，可在表格核对不同序号。
- 大选区的概览默认共享约2000点的预算，按设备分配并分别抽样，额外保留每台的首末点，最多约2000点加设备数；记录较少的设备不会被数据量大的设备挤掉。页面显示抽样说明，**抽样可能漏掉极值**。表格和CSV不抽样，精查时缩小时间范围。
- 单次浏览器导出最多10万条、32MiB，超限会明确报错，不截断。更大导出使用CLI `export`（见[命令参考](cli.md)）。CSV保留历史段、设备序号、原始时间和六项测量字段；不存在的测量字段留空。

## 数据访问与维护

页面通过参数化SQL和SQLite只读连接访问档案，不提供SQL控制台、写入、校时、清空或上传功能。同次页面查询中所有设备的计数、最新数值、分页和抽样图来自同一个短事务快照；CSV另取导出当时的快照。WAL模式下可以继续采集，已经显示的结果不会混入半次提交。

查询设有15秒执行预算，分页和图表限制Python内存用量；图表抽样仍需扫描选区。数据量大时请缩小时间范围。应用只监听127.0.0.1，并关闭Streamlit使用统计；没有做多用户认证，不应改绑公网。浏览器中的数据不会由本程序上传到云端。

不增加缓存数据库、CSV镜像或新的运行数据目录。SQLite schema现为6（浏览仍兼容只读旧库），浏览依赖属于可选扩展，不影响原有采集安装。

## 验证

运行含可选组件的测试：

```sh
uv run --locked --extra viewer python -B tests/run.py -q
```

覆盖只读文件保持不变、读写并发快照、时间边界、重复时间与不同序号、空选区、缺失档案、分页、图表上限、CSV上限，以及真实Streamlit AppTest中的设备切换、筛选、错误提示与导出。CI另设可选浏览组件任务；不安装扩展时只跳过UI测试，数据库查询测试仍运行。

2026-10-28 本机验证：含可选组件的334项测试全部通过；不含组件的独立安装环境334项通过（4项UI测试跳过），安装版CLI/TUI冒烟通过。现有四台设备共37,220条正式观测，对每台完整时间范围查询计数、首屏和概览，约5–11ms；这是本机样本，不代表百万条性能或浏览器绘图耗时。GitHub CI另覆盖Linux Python 3.11/3.13/3.14、macOS Python 3.14、Python包审计及可选组件交互测试。

实现入口为 `kestrel_drop/browse.py`（只读查询与服务启动）和 `kestrel_drop/viewer.py`（页面）。官方组件文档：[Streamlit](https://docs.streamlit.io/)、[AppTest](https://docs.streamlit.io/develop/api-reference/app-testing)。

0.14 起设备选择显示管理编号，正文显示当前受试者代号及其语义提示；它仅帮助核对当前领用，不作为历史数据归属筛选，CSV观测导出不追加当前代号。

0.15.5 增加多设备选择、最新数值表、分色点图和合并导出；切换设备集合会重置分页和旧导出。刷新数据会清除已准备的旧CSV。界面与SQL只读，schema 6及采集行为不变。
