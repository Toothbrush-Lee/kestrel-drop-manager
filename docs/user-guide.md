# 用户手册

适用于 0.9.2。本文按实际工作顺序说明；只做日常采集，阅读前六节即可。TUI 指终端里的交互界面，不需要输入程序命令。文中的字母按键不区分页面提示以外的用途，请使用英文小写输入。

## 1. 安装、启动与第一次采集

需要 macOS / Linux、Python 3.11 或更新版本和 [uv](https://docs.astral.sh/uv/)。Windows 暂不支持本项目的 curses 界面和目录锁。首次启动需要网络下载依赖；安装完成后，本地操作无需联网。

macOS 在 Finder 中打开项目，双击 `Kestrel.command`；也可以在项目目录运行 `uv run kestrel.py`。提示找不到 uv 时，先按 uv 官方说明安装，然后重新启动。建议把终端拉到 100 列 × 24 行以上，最低 68 列 × 18 行；字体乱码时确认终端使用 UTF-8 与中文字体。

1. 打开电脑蓝牙，把 DROP 放在附近，在手机 LiNK 中断开设备连接。系统询问终端蓝牙权限时允许访问。
2. 按 **s** 快速扫描 5 秒；漏扫时按大写 **S** 长扫描 20 秒。↑↓ 选中设备。列表包含型号、编号、附近状态与本地记录。
3. 编号未知时按 **x** 连接读取真实编号并登记，也可以在该行按 Enter。D1/D2 的广播不一定包含编号，蓝牙地址不会被当成序列号。
4. 已有编号时按 **Enter** 下载。连接后软件仍会核对真实序列号、型号和记录格式，不会仅凭广播名称入库。
5. 等待结果页出现。接收达到 100% 后还要完成校验，不能立刻关终端。
6. 按 **v** 预览本地记录，或按 **e** 导出 CSV。原始设备日志不会因下载而被清空。

D1 保存温度；D2 增加湿度、热指数和露点；D3 还有气压和密度高度。设备没有的测量在预览中为 `--`，CSV 中为空；它们不是零。支持标准 D1/D2/D3，其他子型号不能仅凭类似名字推断兼容。

## 2. 读懂列表和结果

**附近**表示本次扫描看到了广播，不能保证随后一定连接成功；**本地档案**表示电脑保存过该设备，设备离线也不会删除档案。广播身份是线索，连接后的 GATT 读取才用于真实身份核验。重复编号、型号冲突需先按 x 核验。

首次采集下载设备当前仍保留的最早历史，以后从电脑保存的位置下载新增部分。设备已经滚动覆盖的记录无法凭软件恢复。没有新增记录也是正常的成功结果。

| 结果 | 含义和下一步 |
| --- | --- |
| 已保存 | 本次下载完成并发布正式记录，检查新增与累计条数 |
| 已经是最新 | 本次没有新增，保留原有档案 |
| 未确认 | 数据已落盘，但整个下载尚未确认完成；暂不进入正式导出 |
| 未完成 / 失败 | 查看对应设备原因与建议，按 l 查看完整日志 |
| 已取消 | 已落盘数据保留；以后可以再下载 |

结果页用 ↑↓、PgUp/PgDn、Home/End 浏览每一台设备。下方详情跟随选中项，v/e 对应选中设备。结果页 r 仅在存在可重试错误时提供：批量任务保留未完成目标，跳过已保存/已最新项和明确不可重试项；保留原并发数与地址映射。身份或数据冲突应先处理原因。软件不会自动反复连接。

首次下载中断时，由于尚不知道实际起始序号，会重新读取最早保留的历史；增量中断可以从可信接收边界继续。设备只报告零条新增但仍有待确认数据时，不会据此伪造完成，应等新样本后重试。

## 3. 批量采集与一百台设备工作流

1. 给设备建立机身编号清单。第一次扫描后，对缺少编号的设备按 x 核验；自定义名称不替代真实编号。
2. 每一批先 s 扫描，确认设备附近且手机已断开。
3. 用空格逐台勾选，或 **Ctrl+A** 勾选本次附近可采集项。**u** 清空全部勾选。列表顶部显示当前批量范围。
4. 按 **j** 设置本次并发数，默认 1，建议先试 2，再按 **a** 开始。并发设置只对本次 TUI 会话生效。
5. 等待结果，逐台检查新增、累计、未确认和失败原因。必要时 r 重试未完成目标。
6. 结束后 b 备份；需要分析的数据再 e 导出。下一次沿用同一数据目录。

有勾选时只处理勾选设备；没有勾选时只处理本次扫描到、身份无冲突且可采集的设备。本地离线档案不自动连接，明确勾选后可以尝试。未知编号和未适配型号会跳过并说明原因。

一百台不代表同时建立一百条蓝牙连接。软件使用 1–8 个连接槽，一台结束后下一台接入；一个任务管理整个批次，一台失败不阻止其他设备。此前已经实测两台并发，3–8 台仍需按电脑蓝牙能力和现场条件验证。并发模式未在初始扫描找到的设备会报告未找到，重新扫描后再试。不要同时开多个下载进程来增加并发，同一目录只允许一个写任务。

## 4. 查看和导出

v 展示最近 100 条正式记录，按设备记录序号由新到旧排列；用 ↑↓、PgUp/PgDn、Home/End 浏览。e 打开导出表单：输出路径必填，开始和结束时间可留空。日期可写 `2026-10-22`，完整时间可写 `2026-10-22 12:30:00`。结束仅写日期时包含当天整天。

CSV 使用 UTF-8 BOM，可用 Excel 打开；已有文件不会覆盖，换一个文件名。删除导出不会影响正式档案。CSV 适合分析和分享，不能代替包含续传状态的 SQLite 备份。

设备时间没有时区，导出保留设备本地时间，不猜测 UTC 偏移。相同时间可以是不同观测，校时后时间也可能倒退；软件按序号管理记录，不按日期去重。

## 5. 设备设置、校时和实时测量

主界面选设备按 **g**，先读取设置。已知扫描地址会传给后台，收到该地址的广播后立即连接，不再等待完整扫描窗口。TUI 每项操作在独立后台进程执行，原扫描的系统蓝牙对象不能通过 JSON 直接复用，因此仍可能短暂显示“定位已知设备”；这不是重新搜集整批设备。只有编号没有地址时，仍需完整扫描检查是否存在重复编号。地址失效时会在同一查找窗口保留广播，超时后按唯一编号尝试定位，不额外增加一轮扫描。所有显示都是上次读取的快照，r 可重新读取；这不会自动改时间。

| 设备页按键 | 设置或操作 |
| --- | --- |
| 1 | 历史采样间隔，单位秒 |
| 2 | 滚动覆盖，on / 开启；off / 关闭 |
| 3 | 当前设备时间：本地 ISO 时间，或 now |
| 4 | 名称：1–20 个可打印 ASCII 字符 |
| 5 | 实时测量更新间隔，2–60 秒；与历史采样独立 |
| 6 | D3 气压计算参考海拔，单位米；不是出厂校准 |
| r / w / f | 重新读取设置 / 读实时测量 / 闪灯定位 |
| b | 数据库备份；与主界面含义一致 |

选择配置项后编辑新值，按 Enter 进入变更预览。核对 **设备编号、旧值、新值和影响**，再按 Enter 才写入并回读验证。预览按 Esc 返回编辑；编辑按 Esc 放弃。一次只修改选择的项目。未读到或不支持的设置不会开放修改。

支持采样间隔：`2, 5, 10, 20, 30, 60, 120, 300, 360, 600, 1200, 1800, 3600, 7200, 21600, 43200` 秒。300 是 5 分钟，600 是 10 分钟。关闭滚动覆盖时，设备满后停止保存新记录，不会腾出容量。

校时 now 使用**提交时电脑的本地时间**，先确认电脑日期与时区。校时只影响之后产生的记录，不修改旧历史。二三月的旧记录可能是上次记录尚未被覆盖，不能用它们判断当前时钟错误，要看 g 页实际读到的时间。

写入断线、取消或校验失败可能意味着部分配置已经生效。软件不会自动回滚或重复写入；界面要求先 r 回读，再决定下一步。配置操作在数据库 `device_actions` 中留有 started / verified / failed_or_unknown 审计，技术核查可用 actions 命令。

w 的实时测量不会写入历史观测库；重复读取也不保证传感器每次更新。f 只闪灯定位。本版不提供清空日志、恢复出厂、修改安全级别或刷固件入口。

## 6. 通用按键与表单编辑

| 页面 / 按键 | 行为 |
| --- | --- |
| 列表 ↑↓、PgUp/PgDn、Home/End | 逐项、翻页、首尾导航 |
| s / S / x / n | 5 秒快扫 / 20 秒长扫 / 核验并登记 / 手动输入编号 |
| Enter 或 d / a | 单台下载 / 按当前范围批量下载 |
| 空格、Ctrl+A、u / j | 勾选、勾选附近、清空 / 设置并发 |
| g / v / e / b | 设备设置 / 记录 / 导出 / 备份 |
| r | 列表刷新本地档案；设备页回读；结果页按提示重试 |
| o / p | 打开数据目录 / 保存位置 |
| i / m | 导入旧 D3 原始档案 / 显式迁移旧格式 |
| l / ? | 查看日志 / 帮助，可从设备页和结果页打开 |
| Esc | 关闭当前层，返回上一层；列表上不会直接退出 |
| c | 取消正在执行的任务，等待连接清理 |
| q | 列表退出；有任务时先取消清理。其他页面返回上一层 |

表单支持 Tab/Shift+Tab 或 ↑↓ 切换字段，Enter 下一项或提交；←→、Home/End 移动光标，Backspace/Delete 删除，Ctrl+U 清空。长路径会随光标横向显示。表单中的 q、c、l 等可打印字符属于输入文本；Esc 返回，c 仍会在存在后台任务时触发取消。

帮助和日志会自动折行，用 PgUp/PgDn、Home/End 浏览，Esc 返回原页面。日志是打开时的快照，关闭再按 l 可更新。TUI 内只保留最近 500 条日志；长期诊断可用 CLI JSON Lines 输出重定向保存。

设备页任务运行时，先等待结束或 c 取消，再 Esc 返回列表。配置确认与文本层按从上到下顺序接收按键，防止看到一个页面却操作另一个页面。

## 数据保存在哪里

TUI 顶部会显示实际路径，按 `o` 打开文件夹。

新安装的默认位置：macOS 为 `~/Library/Application Support/KestrelDrop/`，Linux 为 `$XDG_DATA_HOME/kestrel-drop/`（未设置时使用 `~/.local/share/kestrel-drop/`）。现有项目中发现 `archive/` 档案时，继续使用它，避免升级后看不到旧数据。

```text
数据目录/
├── library.sqlite       所有设备的正式记录和下载恢复状态
├── exports/             按需导出的 CSV
├── backups/             生成的数据库备份
└── legacy/              升级时冻结的旧材料，新安装没有
```

SQLite 运行时可能产生 `-wal`、`-shm` 或 `-journal` 配套文件，由数据库管理，不要手动删除。当前版通过操作系统锁定数据目录防止并发写入，不再产生额外 `.lock` 文件。查询可以与下载同时进行。

数据目录优先级：`--data-dir` → `KESTREL_DATA_DIR` 环境变量 → 保存的位置 → 默认位置。按 `p` 或运行以下命令保存位置：

```bash
uv run kestrel.py configure ~/KestrelData
```

**保存位置不会搬动已有数据。** 换目录时，先备份，再恢复到新目录，最后保存新位置：

```bash
uv run kestrel.py backup /实际路径/kestrel-backup.sqlite
uv run kestrel.py --data-dir ~/KestrelData restore /实际路径/kestrel-backup.sqlite
uv run kestrel.py configure ~/KestrelData
```

设置文件在 `~/.config/kestrel-drop/settings.json`，只保存数据目录，不包含观测。程序测试可通过 `KESTREL_CONFIG_FILE` 指定独立设置文件。

项目中的 `data/originals/` 和 `data/analysis/` 是历史研究资料，不参与日常同步，迁移不会改动它们。`KestrelDocuments/` 是本地提供的官方原始协议资料，由 Git 排除，不是运行依赖。


## 数据怎样管理

**SQLite 是唯一运行档案，CSV 是导出物。** 正式观测按型号保存原始 9 / 16 / 21 字节和解析出的测量值，不再额外保存整行 JSON，也不再维护一份不断增长的正式 CSV。

```text
设备数据块 → CRC / 顺序 / 时间校验 → 数据库待确认块事务 → 回复 ACK
设备完成消息 → 数量 / 游标 / 增长校验 → 一个事务发布正式记录并清理暂存 → 回复完成 ACK
正式记录 → 只读预览 / 按需导出
整个数据库 → 一致备份 → 恢复后继续下载
```

六张表分别保存设备、连续历史段、下载会话、待确认块、正式观测和配置审计。记录身份是“设备 + 历史段 + 绝对游标”。同一设备重置后的历史不会自动与现有历史拼接；当前遇到缺口或游标冲突会停止，尚未提供手动创建新历史段的操作。

正式游标和已接收边界是不同事实：中断时保留待确认块，但它们不进入正式查询。增量重试从可信边界继续，首次下载因为尚不知道设备实际起始游标，会重新请求游标零。完整检查使用 `db`，日常刷新、预览和导出不会扫描旧 CSV 或修改数据库。

详细表结构与事务说明见 [存储设计](storage.md)。

导出包含设备 `serial`、历史段 `history_generation`、记录编号 `absolute_cursor`、设备本地时间、温湿度气压、热指数、露点、密度高度，以及 `record_hex` 原始字节。`block` 和 `position_in_block` 表示接收块位置，`unknown_byte` 是尚未确认含义的字段。`station_pressure_hpa` 是站点气压，不能当作海平面修正气压。


## 备份与换电脑

按 `b` 或运行 `backup`，默认生成在数据目录的 `backups/`。备份使用 SQLite 备份接口，验证数据库结构、原始记录和恢复边界后发布；已有文件不会覆盖。

**当前格式的单个备份包含正式数据和当时的下载暂存，恢复后可以继续同步。** CSV 导出、legacy 旧材料和位置设置不包含在数据库备份内；如果需要长期保留原始迁移证据，请另外复制 legacy。

```bash
uv run kestrel.py backup /实际路径/kestrel-backup.sqlite
# 新电脑：恢复目标必须为空目录
uv run kestrel.py --data-dir ~/KestrelData restore /实际路径/kestrel-backup.sqlite
uv run kestrel.py --data-dir ~/KestrelData db
uv run kestrel.py configure ~/KestrelData
```

恢复不会覆盖已有档案。先检查条数，再继续下载。不要用运行中直接复制主数据库文件代替 `backup`，未合并的 WAL 也可能包含数据。


## 从 0.6 / 0.7 升级到当前版

先退出旧版 TUI，再重新启动。首次下载、登记、设备配置或显式 `migrate` 时，会先在数据目录的 `backups/schema2-before-upgrade-*.sqlite` 或 `schema3-before-upgrade-*.sqlite` 保存并完整核验旧库，再用一个事务升级到 **schema 4**。原始记录、设备编号、游标和待确认块保留；热指数按官方 24 位有符号格式从原始字节重新计算，解码版本升为 v2。升级失败整体回滚。单纯查看和导出不触发升级。

升级后的活动库请用 0.8 或更新版本打开；旧版备份仍可只读核验、恢复，并在下次写入时升级。schema 1 / CSV 旧档案继续使用下面的显式迁移流程。

D1 仅有温度；D2 有温度、湿度、热指数和露点；D3 再增加气压和密度高度。设备没有的字段在数据库中为 NULL、预览为 `--`、CSV 中为空，不补零。默认单次读取上限提高到 20,000 条；超出时会停止，可显式设置 `--maxrows`。首次完整读取可能需要十多分钟，后续只下载新增记录。


## 从 0.5 或更早版本升级

**先关闭旧版 TUI 和下载程序。** 新版不会在查看数据时自动改写旧档案。

在 TUI 主界面按 `m`，或者执行：

```bash
uv run kestrel.py migrate
uv run kestrel.py db
```

迁移依次完成：

1. 保留旧 CSV、JSON、暂存证据和旧数据库快照。
2. 在副本上恢复旧版未完成的文件提交，校验每条原始记录、测量值和绝对游标。
3. 将正式记录及证据完整的增量待确认块写入新数据库。
4. 检查新库，通过后原子切换 `library.sqlite`。
5. 将旧材料归档到 `legacy/migration-日期-编号/`，文件设为只读；日常不再更新它们。

旧数据库与 CSV 冲突、记录损坏、暂存缺少可信检查点时，迁移会停止，保留原文件供检查。软件不会靠丢弃有问题的记录来完成迁移。首次未完成下载的起始绝对游标未知，其原文件保存在 legacy，下一次从设备最早仍保留的历史重新读取。

迁移可以重复运行；如果数据库已经切换、清理旧文件时中断，再执行会继续清理。迁移后发现旧文件被外部修改，会保留该文件并在 `retained_changed_files` 中报告。

只有旧版数据库备份时，也可以把它放到一个单独目录并命名为 `library.sqlite`，用 `--data-dir` 指向这个目录执行 `migrate`。它只能恢复这份旧备份当时已入库的数据；未包含的下载暂存不会凭空恢复。

```bash
uv run kestrel.py --data-dir /实际路径/旧档案目录 migrate
```


## 导入旧完整下载

按 `i`，输入本工具早期下载的完整 CSV；元数据留空时使用旁边的 `.csv.json`：

```bash
uv run kestrel.py import /实际路径/my_history.csv
```

源文件不改动，通过校验后一次事务入库，不产生日常 CSV 副本。同一序列号已有档案时拒绝覆盖。LiNK 官方 CSV 缺少这里需要的原始记录和完成游标，不能作为可续传档案直接导入。


## 常见问题

- **扫描不到设备**：断开手机 LiNK，检查电脑蓝牙、终端权限，靠近设备重试。`scan --timeout 30` 可延长扫描。
- **D1/D2 没显示编号**：选择对应行按 `x` 读取标准 GATT 序列号字段，不会发送配置指令。若设备拒绝读取，软件保留型号并显示失败原因，不会把蓝牙地址冒充编号。
- **重复编号或型号冲突**：保留两个候选项并阻止按编号盲选，用 `x` 按地址逐台核验。广播名称不能覆盖已有档案的设备身份。
- **下载中断**：保留数据库，再次下载。首次中断会从最早仍保留的历史重读；增量中断从可信接收边界续传。
- **有待确认数据，设备报告零条新增**：缺少完整完成确认，数据保持待确认；等设备产生新样本后重试。
- **提示校验失败或游标冲突**：保留数据库和 legacy，查看日志，不手改游标。设备环形缓冲可能覆盖旧记录，及时下载有助于避免缺口。
- **提示正在使用 / 数据库锁定**：等待另一个写入或迁移任务结束。迁移前需关闭旧版本程序。
- **数据库损坏或丢失**：使用备份恢复到空目录。新版不会再通过日常 CSV 自动重建数据库；导出的 CSV 也不包含下载暂存。
- **Git 能备份观测吗**：不能。Git 只管理代码，观测数据库、备份、导出、抓包和个人资料均被忽略。
